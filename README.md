-Выполненные задания

| Проект | Что сделано |
|--------|-------------|
| Task1.Statistics | Статистика случайного массива: сумма, произведение, чётные, больше среднего |
| Task2.InputSort | Ввод с клавиатуры, реверс, сортировка, поиск max/min |
| Task3.Unique | Уникальные элементы без LINQ и HashSet |
| Task4.Exceptions | Обработка FormatException, OverflowException, IndexOutOfRangeException |
| Final.Task | Успеваемость студентов: таблица, лучший студент, средний балл |


-Использованные методы и классы

- string.Join — вывод массива в строку
- Array.Sort — сортировка массива
- Array.IndexOf — поиск индекса элемента
- Random — генерация случайных чисел
- try/catch — обработка исключений
- StringBuilder — эффективная работа со строками
- Циклы for, while, foreach
- Условные операторы if, else, switch


-Как запустить

Каждое задание — отдельный проект. Запуск:

dotnet run --project Task1.Statistics
dotnet run --project Task2.InputSort
dotnet run --project Task3.Unique
dotnet run --project Task4.Exceptions
dotnet run --project Final.Task
